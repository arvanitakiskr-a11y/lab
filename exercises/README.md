# Οι δικές σου ασκήσεις

Γράψε εδώ python_basics.py, test_day06.py και test_day07.py όπως περιγράφει το Word. Αποθήκευσε πριν εκτελέσεις.

Από τον φάκελο lab:

    .venv\Scripts\python.exe exercises/python_basics.py
    .venv\Scripts\python.exe -m pytest exercises/test_day06.py -v

Σε macOS/Linux αντικατάστησε τον interpreter με .venv/bin/python.
Τα exercises δεν εκτελούνται από το σκέτο pytest λόγω του pytest.ini. Δώσε το συγκεκριμένο path. Η λύση answers/test_beginner_reference.py εκτελείται επίσης ρητά, αφού προσπαθήσεις μόνος σου.
